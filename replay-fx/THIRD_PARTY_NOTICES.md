# Bibliothèques tierces

Cette application embarque localement les bibliothèques suivantes pour les exports :

- SheetJS Community Edition 0.20.3 — Apache License 2.0 — https://sheetjs.com/
- jsPDF 2.5.2 — MIT License — https://github.com/parallax/jsPDF
- jsPDF-AutoTable 3.8.4 — MIT License — https://github.com/simonbengtsson/jsPDF-AutoTable

Les données de marché intégrées proviennent de HistData.com. Elles sont utilisées ici pour la simulation et l’entraînement, sans garantie d’exhaustivité ni d’adéquation à une prise de décision financière réelle.
